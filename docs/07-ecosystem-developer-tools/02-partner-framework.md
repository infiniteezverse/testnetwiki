# Partner Application Framework

Protocols, institutional market makers, and liquidity managers can integrate directly with ZENDEX:

* **Automated Market Makers:** Submit execution batches to `ZendexOrderBookManager` via programmatic operator APIs.
* **Institutional Liquidity Providers:** Deploy private capital into `ZendexAmmManager` pools without broadcasting portfolio size or composition.
* **Ecosystem dApps:** Route swap operations through `ZendexRouter` to offer users built-in transaction privacy.
