# Acquiring Testnet Assets

Participants require testnet ETH on Horizen Testnet to pay EVM transaction gas fees:

1. **Horizen Testnet ETH:** Request testnet ETH directly from the official faucet at [https://hub-testnet.horizen.io/](https://hub-testnet.horizen.io/).
2. **Testnet ERC-20 Tokens:** Mint testnet assets (tZEN, tUSDC, tETH, and tZKZ) via the interactive faucet tab on [https://testnet.zendex.fi](https://testnet.zendex.fi).
