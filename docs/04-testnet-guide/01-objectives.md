# Testnet Objectives & Success Metrics

The ZENDEX Public Testnet evaluates platform reliability, proof speed, and contract security prior to Horizen Mainnet release. Key operational targets include:

* Stress-testing Noir circuit verification times across high transaction volumes.
* Validating single-epoch inclusion proof reuse and tree updating mechanics under load.
* Verifying operator execution efficiency for private order book matching.
* Collecting UX feedback on wallet management, key generation, and private deposit workflows.
