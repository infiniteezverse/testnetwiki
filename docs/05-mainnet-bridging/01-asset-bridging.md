# Mainnet ZV1 Asset Bridging

When ZENDEX launches on Horizen Mainnet (ZV1), users will bridge capital using official ecosystem gateways:

* **Ethereum Mainnet → Horizen Mainnet (ETH):** Bridge native ETH directly using the official [Horizen Bridge Portal](https://bridge.horizen.io/).
* **Base / EVM Chains → Horizen Mainnet (USDC):** Cross-chain transfers for native ZEN USDC are routed through Stargate Finance via the [Stargate Horizen USDC Pool](https://stargate.finance/?srcChain=base&srcToken=0xf43eB8De897Fbc7F2502483B2Bef7Bb9EA179229&dstChain=horizen&dstToken=0x57da2D504bf8b83Ef304759d9f2648522D7a9280).
