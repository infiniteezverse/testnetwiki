# Security & Audit Portfolio

ZENDEX protocol security is built on a defense-in-depth model:

* **Dual Defense Program:** Active testing by independent white-hat security researchers via Hacken Dual Defense.
* **Smart Contract Audits:** Comprehensive codebase review covering proxy patterns, access controls, arithmetic precision, and reentrancy vectors.
* **Circuit Verification:** Formal auditing of Noir circuit constraints to guarantee that proof inputs cannot be forged or manipulated.
