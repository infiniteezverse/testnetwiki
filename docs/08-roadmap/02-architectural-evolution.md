# Architectural Evolution

* **Mainnet ZV1 (Launch Version):** Core private ZK-AMM implementation, hidden limit order book, Stargate USDC bridging, and native 10% \$ZEN Staking Fee Splitter integration.
* **ZV2 (Privacy Router & Solver Network):** Implementation of an off-chain intent solver network, advanced order routing, dynamic liquidity aggregation, and full client-side PureFi ZK-Passport attestations.
* **ZV3 (Multi-EVM Privacy Interoperability):** Cross-chain zero-knowledge liquidity bridging, allowing users on external EVM networks to execute shielded transactions on ZENDEX natively.
