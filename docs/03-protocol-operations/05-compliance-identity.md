# Module 5: Compliance & Identity Layer

ZENDEX combines cryptographic privacy with strict risk management frameworks:

* **PureFi ZK-Passport Integration:** Users complete local, client-side identity checks using PureFi's zero-knowledge attestation framework. The user generates a proof that they hold a valid compliance certificate without exposing personal identifiable information (PII) to ZENDEX or on-chain verifiers.
* **AMLBot Risk Scoring:** Before execution, transaction inputs are analyzed via AMLBot to filter out illicit capital pools, protecting overall DEX liquidity integrity while maintaining individual trader transaction privacy.
